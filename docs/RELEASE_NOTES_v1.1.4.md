# Release Notes v1.1.4

## 版本定位

v1.1.4 是 UI 调试可用性优化版本。它不改变 Runtime 协议，不接真实 Omni、真实 TTS、真实云 API 或真实硬件，只把 v1.1.3 的实时会话状态机、输入输出通道和可见信息面板做得更容易调试。

## 新增内容

- 顶部 Hero 从大量架构标签改成三项摘要：当前重点、实时核心、安全边界。
- 新增 `DebugNavigation` 快速跳转导航，支持跳到机器人控制、实时音频/摄像头、Omni 会话、可见信息、插件权限和行为日志。
- 可见信息面板改为 compact 结构：先显示 4 个摘要卡片，再用可折叠详情展示“当前能看到”和“当前不能看到”。
- 修复窄栏里中文和协议字段过度挤压、看起来像乱码的问题。
- 增加响应式布局，较窄窗口下自动改为单栏，避免横向滚动影响调试。

## 保持不变

- `omni.audio_frame.v1` 仍是麦克风输入媒体帧。
- `omni.camera_frame.v1` 仍是摄像头关键帧媒体帧。
- `omni.reply_audio_frame.v1` 仍是服务端输出媒体帧，不是 TTS 结果。
- `omni.interrupt.v1` 仍是唯一的手动用户插话/打断事件。
- `reply_text` 仍只用于字幕、日志和调试。

## 验收点

- 页面顶部不再堆满架构 chip。
- 点击快速导航可以跳到对应调试模块。
- 可见信息面板在右侧栏里不再出现严重挤压换行。
- `npm run build` 通过。

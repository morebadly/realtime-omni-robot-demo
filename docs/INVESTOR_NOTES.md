# 投资人视角说明

## 产品价值

本项目面向下一代可移动 AI 机器人，核心价值不是单纯聊天，而是：

- 实时语音对话
- 视觉关键帧理解
- 动态表情交互
- 插件化能力扩展
- 多网络场景适配
- 透明权限和行为日志

## 成熟交互模型

- 在家：Wi‑Fi + 云端 Omni，最佳主体验
- 出门：eSIM / 实体 SIM + 云端 Omni，轻量可移动
- 无网络：基础宠物模式，触摸/NFC/表情/动作可用

## 为什么先做 Web Demo

Web Demo 可以低成本验证：

- 机器人表情风格
- 插件中心
- 权限系统
- 事实事件设计
- Runtime 架构
- 投资人可视化演示

## 为什么保留本地调试

本地部署不一定是最终消费级产品模式，但它对开发阶段很重要：

- 快速调试实时交互
- 降低早期 API 成本
- 在云端服务完成前验证产品闭环
- 让 Model Adapter 具备可替换能力

## 核心壁垒

1. 多场景连接能力：Wi‑Fi / eSIM / 实体 SIM / 离线
2. 插件中心：让用户和开发者扩展机器人能力
3. 表情系统：让机器人更像有生命的终端
4. 权限透明：用户知道机器人能看到什么、做了什么
5. 云端优先但可本地调试：工程落地灵活
